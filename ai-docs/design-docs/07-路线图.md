# 07 · 路线图

> 状态：草案 v0.1
>
> 原则：**每个里程碑只增加一个"用户能感觉到"的能力**，且必须能在真机上验收。
> 规模按"一个人日"估，只用于排序，不作为承诺。

## 1. 总览

| 里程碑 | 一句话 | 规模 | 关键风险 |
| --- | --- | --- | --- |

## 2. 里程碑展开

### M0 · 技术验证（两个 spike，可丢弃）

**目标**：把两个"纸面上成立、实际上可能不成立"的假设打掉。

| Spike | 内容 | 验收 |
| --- | --- | --- |
| A · 遮罩 | 4 块纯色分层窗口挖一个洞 + 一张卡片 + 关闭按钮 | 洞外的点击能穿透到记事本；关闭按钮能点；Alt+Tab 看不到；任务栏无图标 |
| B · 截图 | `BitBlt` 截屏 + `WDA_EXCLUDEFROMCAPTURE` | 遮罩显示时截图里**没有**遮罩；125% 缩放下坐标不偏 |

**失败预案**（写在 08 章风险表里）：

- 若 `HTTRANSPARENT` 导致下层 hover 不刷新 → 关闭按钮改为独立小窗口
- 若 `WDA_EXCLUDEFROMCAPTURE` 对 `BitBlt` 无效 → 截图前主动隐藏 + 等两帧

**明确不做**：不做架构、不建 workspace、不写测试。这段代码是要扔的。

**M0 验证结果（2026-10-19，Windows 10 19045 / 1920×1080）**

两个 spike 合并成一个 `spotlight probe` 探针跑完了，**三个假设全部成立**：

| 检查 | 指标 | 结论 |
| --- | --- | --- |
| 遮罩压暗 | 遮罩区平均亮度差 134.67 | 正常 |
| 洞内不受影响 | 洞区平均亮度差 **0.00** | 精确 |
| 截图排除 | 设置 `WDA_EXCLUDEFROMCAPTURE` 后整区亮度差 **0.15** | 基本等于没变 |
| 扩展样式 | layered / transparent / no_activate / tool_window / topmost 全为真 | 通过 |

**关键结论**：`WDA_EXCLUDEFROMCAPTURE` 对 `BitBlt` **有效**，所以"截图前主动隐藏遮罩"
从"主路径"降级为"保险丝"——保留，但不再依赖它。这一条省掉了截图流程里一次隐藏/恢复
的时序处理。

> 剩余的未知项：`HTTRANSPARENT` 之后下层窗口的 hover 是否正常刷新（要真机点一下才能确认），
> 以及混合 DPI 下的坐标。前者不影响架构，后者由 M2 的逐屏窗口天然规避。


### M1 · 骨架 v0.1

**目标**：`spotlight show --rect ... --text ...` 能出一个静态画面，守护进程能自启自退。

- workspace 切分（core / render / platform / cli）
- 协议 v1：`show` / `clear` / `status`
- 守护进程：单实例、按需拉起、空闲 3 分钟退出
- 静态效果：`ring` + 纯文本卡片（固定位置，不避让）

**完成标准**

```bash
spotlight show --rect 100,100,200,60 --text "hello"
```
第一次调用约 100 ms 内出画面；第二次调用 < 15 ms；`clear` 立即消失；
重复调用不会留下第二个画面。

**不做**：坐标映射（先用 `--space screen`）、倒计时、动画、多目标。

**M1 完成（2026-10-19）**

| 项 | 状态 |
| --- | --- |
| 协议 v1（NDJSON） | ✅ `show` / `clear` / `status` / `ping` |
| 守护进程 | ✅ 单实例、按需拉起、空闲 180 秒自退 |
| 遮罩 | ✅ 矩形分解 + 分层窗口 |
| 效果层 | ✅ `UpdateLayeredWindow` 逐像素 alpha |
| 光环 + 文案卡片 | ✅ 已实现（卡片提前做了八方位避让） |
| 文字 | ✅ 改用 GDI 出 alpha 掩膜，未引入 cosmic-text，体积预算反而更宽 |

实测一次 `show` 到画面出现，肉眼无延迟；`clear` 立即消失；重复调用不会叠加画面。
**未做**：关闭按钮、倒计时进度条、悬停暂停（都在 M2/M3）。

### M2 · 可用 v0.2

**目标**：**坐标真的对**，并且能自己消失。

- `capture` 命令 + mapping + `--capture` 引用
- 强制坐标空间声明（D5a）
- DPI 感知、逐屏窗口、显示器变化时重建
- 倒计时 + `auto` 估算 + 进度条
- 关闭按钮、全局热键、`--timeout 0`

**完成标准**

| 场景 | 期望 |
| --- | --- |
| 100% / 125% / 150% / 200% 缩放 | 框与目标边缘误差 ≤ 1 px |
| 双屏（副屏在左，负坐标） | 框出现在正确屏幕 |
| 截图 → 量 → show 全流程 | 一次成功，无需手动换算 |
| 中途拔掉显示器 | 画面消失，不崩 |

**不做**：多目标、效果扩展、配置项。

**M2 进行中（2026-10-19）**

| 项 | 状态 |
| --- | --- |
| `capture` + 坐标映射 | ✅ 单屏；1280×720 图映射回 1920×1080 屏，实测 1.5 倍换算正确 |
| 坐标空间强制（D5a） | ✅ 两样都不给就报错，退出码 3，错误带下一步提示 |
| 倒计时 + 进度条 | ✅ 100ms 重绘，条随剩余时间收缩 |
| 悬停暂停 | ✅ `GetCursorPos` 轮询，不用全局钩子 |
| 关闭按钮 | ✅ `HTTRANSPARENT` 挖孔，全屏只有 28×28 可点 |
| DPI 感知 | ✅ PerMonitorV2，但只在 100% 缩放下验证过 |
| 多显示器枚举 | ❌ 仍只认主屏 |
| 全局热键 | ❌ 未做 |

**实测**（release，1920×1080 / 100%）：`capture` 106 ms、`show` 62 ms、
`status`（含冷启动守护进程）80 ms、可执行文件 **737 KB**——体积预算 5 MB 用掉不到 15%。

### M3 · 好看 v0.3

**目标**：从"能看"到"想用"。

- 效果注册表 + `ring` / `glow` / `arrow` / `brush` / `pulse` / `crosshair` / `badge`
- 卡片八方位排布 + 打分避让
- 悬停暂停（`GetCursorPos` 轮询）
- 入场淡入、退场淡出
- 两套主题（深/浅）+ accent 配置

**完成标准**：录一段 20 秒的操作视频，发给没看过设计文档的人，能说出"它在让我点哪里"。

**不做**：跟随窗口、步骤流。

**M3 部分完成（2026-10-19）**

| 项 | 状态 |
| --- | --- |
| 效果注册表 | ✅ `Effect` trait + `build_effects`，未知名字忽略并回落 |
| `ring` / `brush` | ✅ 手绘圈按目标位置做种子，重绘稳定不抖 |
| 多目标 | ✅ `--rect` 可重复，卡片按所有目标的并集避让 |
| 入场淡入 | ✅ 120ms；动画期间 16ms 定时器，结束立刻降回 100ms |
| 脉冲 / 圈画生长 | ❌ 仍是静态帧 |
| 主题（深/浅） | ❌ |

顺带修了一个视觉细节：效果窗口的"洞"从"目标外扩效果边距"改回固定 6px。
否则圆形的圈画会落在一块**亮矩形**里，看起来像贴纸而不是画在屏幕上。

### M4 · 完整 v0.4

**目标**：能应付真实使用的边角。

- 多目标（`--file` 输入）
- `--id` 幂等替换
- `doctor`（DPI、捕获排除、热键占用、权限）
- 配置读写、快捷键配置
- 全量错误文案打磨（每条都带 `hint`）
- 日志与 `--verbose`

**完成标准**：连续做 20 次真实教学任务，零崩溃、零坐标错位；每次失败都有可读的 `hint`。

### M5 · 发布 v1.0

**目标**：一个能发给别人的文件。

- 体积压到 5 MB 内（必要时切 DirectWrite 排版）
- bench 命令 + 冷/热启动达标
- `install` / `uninstall`
- 发布页：截图、GIF、SHA256、用法示例、AI 侧 prompt 片段
- 一份"如何在 Claude / Cursor / 自建 Agent 里接"的短文

**完成标准**：在一台干净的 Windows 10/11 上，下载 → 解压 → 执行 → 成功，全程不需要装任何东西。

### M6 · macOS v1.1

**目标**：同一套 CLI，第二个平台。

- `spotlight-mac`：NSScreen 坐标翻转、NSWindow 层级、`sharingType = .none`
- ScreenCaptureKit + TCC 权限引导
- `.app` bundle、universal2、codesign + 公证
- 权限缺失时的降级与提示

**完成标准**：在 M 系列芯片和外接屏上，`show` / `capture` 全流程与 Windows 行为一致。

## 3. 明确排在后面的（backlog）

| 功能 | 价值 | 为什么先不做 |
| --- | --- | --- |
| UIA 吸附（`--snap uia`） | 让 AI 只需要"大概在哪" | UIA 慢且不稳定，得先有稳定的超时与降级 |
| 点击观察（不拦截） | 自动推进步骤 | 需要轮询键盘/鼠标状态，属交互增强，不是核心 |
| 步骤流 `tour` | 一次描述多步 | 界面会变，多步必须由 AI 逐步驱动 |
| MCP 入口 | 客户端集成更顺 | CLI 语义未稳定前包一层会返工 |
| 托盘图标 | 用户可随时关 | 默认不需要 |
| 主题包 / 自定义效果 | 品牌与偏好 | 先证明默认样式够用 |
| 录制模式（生成 GIF） | 做教程 | 是另一个产品 |

## 4. 排期的三个前提

1. **M0 必须先做**。它只花 2–3 天，但能避免"做完 M3 才发现点击穿透有坑"。
2. **M2 之前不要碰效果**。坐标不准的时候，好看的框只会让人更生气。
3. **M5 的体积检查要提前到 M3 之后**。如果那时已经 7 MB，越往后越难压。
