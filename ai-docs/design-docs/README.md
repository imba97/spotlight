# Spotlight 设计文档

> 状态：设计完成 · 草案 v0.4 · 2026-10-19
>
> 本目录是 Spotlight 的设计档案。没有定稿的结论标注「待决策」，都收在各章末尾。

## 一句话

**Spotlight 是给 AI 用的一支激光笔。**

```
AI 截图 → 锁定目标矩形 → 调 Spotlight 高亮 + 配一句话 → 用户照着点
```

## 为什么需要它

"点开始选项卡里、字体右边那个按钮"——用户要在几十个图标里找一个自己不认识的东西。
AI 能准确说出"它在哪"，只是缺一个**把坐标变成视觉指示**的通道。

截图加红框也算解法，但静态图会过期（窗口一滚就错），也没法跟着真实窗口走。
Spotlight 画的是**活的**遮罩：窗口动了、缩放变了，重新调一次即可。

## 已定决策

| # | 决策 | 理由 | 详见 |
| --- | --- | --- | --- |
| D1 | 进程形态＝**按需拉起 + 空闲自退**的守护进程 | 首帧快，又不留常驻负担 | [01](01-形态与架构.md) |
| D2 | AI 入口＝**只做 CLI + JSON** | Agent 侧最大公约数 | [01](01-形态与架构.md) |
| D3 | **纯展示**，只留关闭按钮一个可点区域 | 拦截点击会让用户无法操作目标 | [03](03-渲染与视觉.md) |
| D4 | **Windows 先行，macOS 后补** | 手上没有 Mac；平台层只需 8 个方法 | [01](01-形态与架构.md) |
| D5a | 坐标**必须显式声明空间**，不给就报错 | 静默偏 30px 比报错更伤信任 | [02](02-坐标与截图.md) |
| D6 | 视觉默认**极简**，效果做成**可插拔注册表** | 后续要加箭头/手绘圈，不能重写渲染 | [03](03-渲染与视觉.md) |
| D7 | 时长由 AI 定；`0` 常驻；**悬停文字暂停**；都有手动关闭；限时显示进度条 | 时长应跟着文案走 | [04](04-交互与状态机.md) |
| D8 | Rust + 原生窗口 API，不用 WebView | 体积与冷启动是产品前提 | [01](01-形态与架构.md) |
| D11 | 多目标**进 v1**；步骤流不进 | 多目标成本低，步骤流必须重截图 | [04](04-交互与状态机.md) |

## 关键数字速查

| 项 | 值 |
| --- | --- |
| 遮罩压暗 | 55% |
| 光环 | 3px，双色描边（白内衬 + accent） |
| 卡片 | 最大 360px 宽，正文 14px，圆角 10 |
| 唯一可点区域 | 28×28 关闭按钮 |
| 默认时长 | `clamp(5 + 字数/6, 6, 45)` 秒 |
| 冷启动到首帧 | < 150 ms |
| 热调用 | < 30 ms |
| 常驻内存 | < 12 MB |
| 单文件 | < 5 MB |
| 遮罩内存 | 与分辨率无关（矩形分解，无位图） |

## 命名

| 词 | 含义 |
| --- | --- |
| **target** | 被高亮的矩形区域 |
| **mask** | 除 target 外整体压暗的遮罩 |
| **effect** | 画在 target 附近的视觉元素：光环、箭头、圈画、脉冲…… |
| **callout** | 文案卡片（标题 + 正文 + 进度条 + 关闭按钮） |
| **scene** | 一次调用描述的完整画面（1..N 个 target + 若干 effect） |
| **session** | 守护进程里一个可被寻址的 scene 实例 |
